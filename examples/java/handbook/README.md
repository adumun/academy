# Ejemplos ejecutables del Handbook

Piloto: métodos. Cada concepto tiene fuentes y pruebas; no un repositorio por cápsula. JDK 21 y Node.js. `npm run sync:snippets` regenera los bloques registrados; `npm run validate:snippets` detecta divergencias; `npm run test:java-sources` compila y ejecuta las clases y pruebas reales. La suite histórica de 34 ejemplos sigue disponible mediante `npm run test:java-examples`. No se ha migrado el resto del Handbook. Los proyectos integradores permanecen en `examples/java/projects/`.
