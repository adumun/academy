# Cápsula del Tiempo FX · R00

Snapshot adaptado para Academy. Requiere JDK 21 y Maven instalado. Abre el POM en tu IDE o ejecuta `mvn compile` y `mvn javafx:run` en esta carpeta. No incluye configuraciones personales ni Maven Wrapper binario; las fuentes y el POM son locales. No se ha certificado la ejecución de esta adaptación (ADU-236).
