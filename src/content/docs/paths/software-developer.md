## Alcance inicial

Esta ruta agrupa conocimientos reutilizables para estudiantes y colaboradores. No representa todavía un programa de onboarding completo ni una certificación.

## Capacidades disponibles

| Capacidad | Recursos |
| --- | --- |
| Construir y ejecutar proyectos | [Maven](/handbook/tools/maven/) |
| Modelar datos y contratos | [Java y POO](/handbook/java/fundamentals/) |
| Consultar y persistir información | [SQL](/handbook/sql/) y [JDBC](/handbook/java/jdbc/) |
| Separar responsabilidades | [MVC y DAO](/handbook/architecture/) |
| Diagnosticar problemas | [Diagnóstico](/handbook/troubleshooting/) |

## Cómo practicar

Selecciona un problema, explica el comportamiento esperado, implementa una solución mínima y comprueba el resultado. Registra qué aprendiste y qué necesitas consultar nuevamente. No es necesario completar toda la ruta para resolver una duda puntual.

## Límites

Git, terminal, Docker, APIs y otras tecnologías se incorporarán cuando sus materiales hayan sido revisados. No se duplican contenidos por audiencia.
