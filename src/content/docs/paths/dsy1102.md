## Objetivo de la ruta

Integrar una [interfaz de escritorio JavaFX](/handbook/java/javafx/) con [MariaDB](/handbook/sql/relational-model/) mediante Java y [JDBC](/handbook/java/jdbc/), aplicando [CRUD](/handbook/java/jdbc/crud/) (crear, leer, actualizar y eliminar registros) y separación [MVC/DAO](/handbook/architecture/) (organización de la vista, modelo, controlador y acceso a datos). Esta ruta es una recomendación para estudiar, no una secuencia obligatoria ni una evaluación oficial.

## Si una ficha presupone conocimientos que aún no dominas

Consulta directamente [genéricos](/handbook/java/generics/), [colecciones](/handbook/java/collections/), [interfaces](/handbook/java/interfaces/), [excepciones](/handbook/java/exceptions/) o [lambdas](/handbook/java/lambdas/). Para comprender el comportamiento de la interfaz, revisa [ObservableList](/handbook/java/javafx/observable-list/) y [eventos](/handbook/java/javafx/events/). No necesitas repetir las explicaciones que ya comprendes.

## Práctica recomendada

1. Construye la aplicación con el laboratorio guiado.
2. Usa los microdesafíos para reforzar brechas.
3. Comprueba comprensión con Detective JDBC.
4. Realiza el ensayo de forma autónoma.
5. Revisa los errores consultando las fichas pertinentes.

Las actividades obligatorias, fechas y ponderaciones se informan por AVA. Los recursos complementarios no sustituyen las instrucciones institucionales.

## Autoevaluación

Antes de rendir, verifica que puedes configurar el entorno, ejecutar consultas parametrizadas, mapear resultados, implementar CRUD, actualizar TableView, validar formularios y comprobar persistencia después de reiniciar. No marques una habilidad solo porque leíste su ficha.
