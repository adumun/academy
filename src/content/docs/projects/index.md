Un proyecto integra conocimientos para resolver un problema significativo. A diferencia del [Handbook](/handbook/), que explica conceptos independientes, aquí los conceptos se combinan alrededor de un dominio. A diferencia de Academic Labs, el resultado es una solución que puede evolucionar y cuyos cambios deben poder justificarse.

## Elige un proyecto

| Proyecto | Experiencia | Resultado |

| [Cápsula del Tiempo FX](/projects/time-capsule-fx/) | Incremental; JavaFX y persistencia | Registro de mensajes futuros, con dos recorridos de almacenamiento |

## Cómo trabajar

1. Comprende el requerimiento y decide qué conocimientos necesitas consultar.
2. Implementa un cambio pequeño que tenga un resultado observable.
3. Ejecuta sus pruebas, incluidos casos negativos; conserva evidencia y explica las decisiones.
4. Continúa desde el checkpoint estable del mismo proyecto, no desde otro laboratorio.
5. Consulta las implementaciones de referencia después de realizar tu intento; no son requisitos de diseño universales.

Cada proyecto declara requisitos, incrementos, checkpoints, procedencia y límites. La aceptación se comprueba en tu entorno local. La web no ejecuta Java ni certifica dominio de competencias, no registra progreso individual ni recibe entregas. Si necesitas reforzar una habilidad, usa [Academic Labs](https://academic-labs.adumun.cl/). Si estudias DSY1102, utiliza también la [ruta de consulta](/paths/dsy1102/).
